# تحديث تطوير قبس — 14 نوفمبر 2026

## النطاق

تمت مراجعة مستودع GitHub:

```text
Ali-awwww/qabasapp
```

وتركزت الجولة على مسار **Qabas Studio**، خصوصاً تنظيم بوابة الاستوديو وربط مكتبة الوسائط واستوديو الصور ومسار Higgsfield مع الحفاظ على حماية الجلسات الموجودة.

## التغييرات المنفذة

### 1. بوابة Studio

- تنظيم فئات الفيديو والصور والصوت داخل `StudioGatewayScreen`.
- إضافة مسار واضح إلى `HiggsfieldStudioScreen`.
- تحسين قابلية اكتشاف البطاقات والتبويبات وتسمياتها العربية.
- إضافة اختبار Compose/Robolectric لتبديل تبويبات البوابة.

### 2. حفظ مصدر الدخول

- أصبح `CentralMediaBrowserScreen` يعود إلى الشاشة التي فتحته فعلياً، سواء كانت الرئيسية أو بوابة Studio.
- أصبح `PhotoStudioScreen` يعود إلى مصدر الدخول الصحيح.
- تمرير مسار الصورة المختارة من مكتبة الوسائط إلى استوديو الصور أصبح صريحاً، مع تنظيفه بعد الانتقال أو الحفظ.
- أضيفت حماية مسار Higgsfield إلى مسارات الإنتاج التي تتطلب جلسة مصادق عليها.

### 3. مسار Higgsfield

- اختيار صورة من الجهاز.
- إدخال prompt.
- إرسال الطلب عبر بوابة الخادم الموجودة بدلاً من وضع مفتاح المزود داخل APK.
- عرض التقدم والحالة ومعاينة الفيديو الناتج عند توفره.

## التوثيق المحدث

- تم تحديث `docs/STUDIO_RESTRUCTURE.md` بتفاصيل بوابة Studio ومسارات العودة وحدود الاعتماد على Higgsfield.
- لم تُحذف الشاشات الأصلية.
- لم تُضاف أسرار أو مفاتيح API إلى المستودع أو التطبيق.

## التحقق

تم تنفيذ:

```text
git diff --check
```

وسيتم الاعتماد على GitHub Actions للتحقق من Build وCodeQL وSecret Scan بعد دفع الفرع. فحص Mintlify خارجي عن كود Android وقد يفشل مستقلاً عن البناء.

## حدود مؤكدة

- نجاح وجود مفتاح Higgsfield لا يثبت نجاح توليد فيديو فعلي؛ ذلك يحتاج خزنة الخادم والاتصال بالمزود.
- اختبار الجهاز الفعلي، اختيار صورة من Android، دورة رفع الصورة، ومعاينة الفيديو تحتاج جهازاً أو محاكي Android.
- الدفع والفوترة خارج نطاق هذه الجولة.

## نسبة الإنجاز

ضمن نطاق تحسين بوابة Studio ومسارات التنقل المرتبطة بها، تم تنفيذ الكود والتوثيق في هذه الجولة. تبقى اختبارات الجهاز والتوليد الخارجي كتحقق تشغيلي، وليست عيوباً مثبتة في الكود.
