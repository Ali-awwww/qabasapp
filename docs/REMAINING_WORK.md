## عناصر تحتاج إجراءً خارج المستودع

### سر خزنة المفاتيح

تم نشر Edge Function `qabas-key-vault` على مشروع Supabase الأصلي وهي بحالة `ACTIVE`. ما زال يلزم ضبط السر التالي في إعدادات Edge Functions في Supabase:

```text
QABAS_KEY_VAULT_SECRET
```

يجب أن يكون سرًا عشوائيًا طويلًا، وألا يُضاف إلى Git أو APK أو رسائل المحادثة. بعد ضبطه، يجب اختبار عمليات `put/get/delete` بحساب مصادق عليه.

### اختبارات الجهاز

لا يمكن إغلاق البنود التالية ساكنًا من بيئة البناء فقط:

- فتح مشروع محفوظ واستعادة `workspace_v1` على جهاز آخر.
- رفع وتنزيل تسجيل مشروع مع انقطاع واستئناف الشبكة.
- اختبار Media3 وملفات `file://` وروابط HTTPS ودورة حياة المشغل.
- اختبار aspect ratio والصوت.
- أخذ screenshot للمقارنة بين معاينة Compose وتصدير Canvas RTL.

### الدفع والفوترة

ما زال الدفع الحقيقي خارج نطاق الإصلاح البرمجي الحالي، ويحتاج مزود دفع، PaymentIntent، webhook، وledger خادمي للتحقق من الفاتورة قبل منح الاشتراك.
