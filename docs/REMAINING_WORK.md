## عناصر يمكن لـ Manus إكمالها لاحقًا

1. قراءة نتيجة Build وCodeQL للـ commit الأخير ومعالجة أي خطأ جديد إن ظهر.
2. إصلاح أو عزل فحص Mintlify إذا ظهر مصدره في إعدادات GitHub أو تكامل التوثيق.
3. مراجعة مسارات العيوب عالية الأولوية المتبقية في `docs/SCREEN_DEFECTS.md`، خصوصًا الرسائل الوهمية ومسارات الفشل الصامتة.

### أولوية متوسطة

1. استبدال polling بتحديث عند التركيز فقط إذا أظهرت القياسات أن 30 ثانية مع backoff غير كافية.
2. مراجعة تنظيف الملفات القديمة في `filesDir/agent_sessions` عند حذف الحساب أو تسجيل الخروج.

### أولوية صيانة

1. تقسيم `SettingsScreen.kt` و`DeveloperDashboardScreen.kt` إلى مكونات وملفات أصغر.
2. إزالة أو إعادة صياغة البنود التاريخية في `SCREEN_DEFECTS.md` عندما تختلف أرقام الأسطر عن الكود الحالي.
3. إضافة اختبارات وحدة لمسارات فشل التحديث، الكاش، وكشف المدينة.

## عناصر تحتاج إجراءً خارج المستودع

### سر خزنة المفاتيح

تم نشر Edge Function `qabas-key-vault` على مشروع Supabase الأصلي وهي بحالة `ACTIVE`. ما زال يلزم ضبط السر التالي في إعدادات Edge Functions في Supabase:

```text
QABAS_KEY_VAULT_SECRET
```

يجب أن يكون سرًا عشوائيًا طويلًا، وألا يُضاف إلى Git أو APK أو رسائل المحادثة. بعد ضبطه، يجب اختبار عمليات `put/get/delete` بحساب مصادق عليه.

### اختبارات الجهاز

لا يمكن إغلاق البنود التالية ساكنًا من بيئة البناء فقط:

- فتح مشروع محفوظ واستعادة `workspace_v1` على جهاز آخر.
- رفع وتنزيل تسجيل مشروع مع انقطاع واستئناف الشبكة.
- اختبار Media3 وملفات `file://` وروابط HTTPS ودورة حياة المشغل.
- اختبار aspect ratio والصوت.
- أخذ screenshot للمقارنة بين معاينة Compose وتصدير Canvas RTL.

### الدفع والفوترة

ما زال الدفع الحقيقي خارج نطاق الإصلاح البرمجي الحالي، ويحتاج مزود دفع، PaymentIntent، webhook، وledger خادمي للتحقق من الفاتورة قبل منح الاشتراك.
