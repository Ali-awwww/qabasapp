# سجل عيوب الشاشات — جدول الإصلاح

> هذا الملف يوثّق عيوباً **حقيقية مُستخرجة من فحص الكود** لكل شاشة على حدة، بالترتيب من أول شاشة في مسار التطبيق.
> كل عيب موثّق بموقعه في الكود (ملف : سطر) ودرجة خطورته، ليُستخدم كجدول إصلاح مباشر.
> لا يُضاف أي عيب هنا إلا بعد التحقق منه في الكود فعلياً.

**مسار الفحص:** التحميل ← الميثاق ← الدخول ← التسجيل ← استعادة كلمة المرور ← الرئيسية ← بوابة الاستوديو ← قمرة الإنتاج ← استوديو الحديث ← استوديو الصور ← استوديو الأصوات ← MoneyPrinter ← استوديو يوتيوب ← الملقن ← (تتمة)

**مقياس الخطورة:** 🔴 عالٍ (يؤثر على الوظيفة أو الاستقرار) | 🟡 متوسط (تجربة مستخدم أو أداء) | 🟢 منخفض (تنسيق/جماليات/تقنية)
