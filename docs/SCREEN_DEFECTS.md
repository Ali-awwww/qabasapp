# سجل عيوب قبس — حالة موحدة

آخر تحديث: 2026-11-22

هذا الملف يميز بين العيب البرمجي المؤكد، والتحسين المنفذ، والبند الذي يحتاج اختبار جهاز فعلي. لا تُعد بنود اختبار الجهاز عيوباً مثبتة في الكود قبل تنفيذ الاختبار.

## عيوب أُصلحت

### 1. فقدان حالة إعجاب الريلز بعد العودة

- **الحالة:** تم الإصلاح.
- **المعالجة:** إعادة فحص الإعجابات عند العودة إلى التطبيق، رفع مهلة القراءة، وإضافة إعادة المحاولة عند فشل الشبكة.

### 2. الرجوع من Higgsfield أثناء التوليد

- **الحالة:** تم الإصلاح.
- **المعالجة:** زر الرجوع النظامي وزر الرجوع العلوي يلغيّان عملية التوليد بدلاً من مغادرة الشاشة وترك coroutine تعمل.

### 3. فقدان فيديو Higgsfield داخل cache فقط

- **الحالة:** تم الإصلاح.
- **المعالجة:** إضافة تصدير عبر `CreateDocument` إلى موقع يختاره المستخدم مع النسخ على `Dispatchers.IO`.

### 4. تغيير إعدادات Higgsfield أثناء التوليد

- **الحالة:** تم الإصلاح.
- **المعالجة:** تعطيل الوضع والمدة وحركة الكاميرا أثناء الطلب.

### 5. مغادرة Photo Studio أثناء المعالجة

- **الحالة:** تم الإصلاح.
- **المعالجة:** منع الرجوع العلوي والنظامي أثناء `processing` أو `isGeneratingAi`، مع عرض تنبيه عربي واضح.

### 6. العودة الخاطئة من مكتبة الوسائط واستوديو الصور

- **الحالة:** تم الإصلاح.
- **المعالجة:** حفظ مصدر الدخول وتمرير الصورة المختارة صراحةً إلى Photo Studio.

### 7. بقاء Photo Studio في حالة المعالجة بعد استثناء إنتاج

- **الحالة:** تم الإصلاح.
- **المعالجة:** إحاطة تصدير الصورة وإنتاج الفيديو وتحريك Higgsfield بـ `try/catch/finally`، مع إبقاء `CancellationException` قابلة للانتشار وإعادة الشاشة إلى الخطوة السابقة برسالة عربية عند الفشل. يضمن `finally` تحرير `processing` حتى عند فشل المحرك أو الشبكة.

### 8. تنزيل التلاوة بلا مهلات شبكة صريحة

- **الحالة:** تم الإصلاح.
- **المعالجة:** استبدال `URL.openStream()` باتصال `HttpURLConnection` بمهلة اتصال 15 ثانية ومهلة قراءة 30 ثانية، مع فحص رمز HTTP وإغلاق الاتصال في `finally` قبل متابعة إنتاج الفيديو أو عرض رسالة الفشل.

## بنود تحتاج اختبار جهاز فعلي

هذه البنود ليست عيوباً مؤكدة من الفحص الساكن:

- الضغط على الرجوع أثناء توليد Higgsfield من الزر العلوي ومن زر النظام.
- اختيار موقع حفظ الفيديو وفتح الملف من تطبيق الملفات.
- اختيار صورة من مكتبة الوسائط ثم العودة إلى Photo Studio.
- اختبار التحديثات وxdelta على Android 13+ مع إغلاق التطبيق وDoze.
- اختبار مزامنة إعجاب الريلز بعد قتل العملية وإعادة فتح التطبيق.

## قيود خارج نطاق التطبيق

- فشل فحص Mintlify تابع لتكامل GitHub خارجي؛ لا يوجد Workflow أو ملف إعداد Mintlify داخل المستودع الحالي.
- نجاح `provider_status` لا يثبت صلاحية مفتاح Higgsfield أو نجاح توليد فعلي.
- الدفع والفوترة خارج نطاق الإصلاح الحالي.
