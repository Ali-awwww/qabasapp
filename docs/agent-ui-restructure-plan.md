- شاشة رئيسية واحدة فقط: `AiStudioAgentScreen` (تُدمج فيها كل الوظائف).
- `AgentRoomSection` تتحول إلى **مكوّنات مشتركة**، وتُحذف كواجهة مستقلة من `DeveloperDashboardScreen`.
