## التغييرات المنفذة

### 1. إصلاح فشل بناء طلب الدمج

أظهر آخر تشغيل لـ GitHub Actions أن البناء وصل إلى مرحلة اختبارات الوحدة، لكنه فشل في الاختبار:

```text
ProjectWorkspaceCodecTest > workspace snapshot round trips scenes resources and source details
```

سبب المشكلة أن اختبار JSON كان يعمل خارج بيئة Android/Robolectric، رغم أن `ProjectWorkspaceCodec` يستخدم `org.json` ومكونات Android. أضيف إلى الاختبار:

- `RobolectricTestRunner`
- `@Config(sdk = [35])`

وبذلك أصبح الاختبار يستخدم نفس نمط الاختبارات الأخرى التي تتعامل مع Android و`org.json`.

بعد إعادة الفحص ظهر خطأ Kotlin مستقل في قراءة قيمة التوكن المشفر؛ تم تحويل القراءة nullable إلى قيمة `String` آمنة باستخدام `orEmpty()`، ودُفع التصحيح في commit لاحق.

### 2. حماية توكنات منصات التواصل

تم إصلاح تخزين توكنات YouTube وTikTok وInstagram وX وFacebook:

- لم تعد التوكنات تُكتب في `qabas_social_accounts` كنص صريح.
- أصبحت تُحفظ عبر `AgentPrefs` المشفر باستخدام Android Keystore/EncryptedSharedPreferences.
- أضيف ترحيل تلقائي لمرة واحدة من المفاتيح القديمة.
- بعد الترحيل تُحذف القيمة القديمة من SharedPreferences.
- عند فصل الحساب تُمسح قيمة التوكن المشفرة.
- بقيت بيانات العرض والإحصائيات غير الحساسة في مخزن الحسابات العادي.

### 3. توثيق سجل العيوب

تم تحديث `docs/SCREEN_DEFECTS.md` ليعكس:

- إغلاق عيب حفظ الصوت دون عينة، والذي كان قد عولج في الكود ولم يكن السجل محدثًا.
- إغلاق عيب توكنات المنصات غير المشفرة.
- توثيق إصلاح اختبار مساحة العمل.
- تحديث تقدير الإنجاز المرحلي إلى 82% ضمن نطاق الكود مع استبعاد الدفع.

## التحقق

تم تنفيذ الفحوص التالية قبل الحفظ:

```text
git diff --check
```

كما تمت قراءة سجل GitHub Actions وتحديد أن الفشل الحالي كان اختبار وحدة واحدًا، وليس خطأ Kotlin compilation.

بيئة Manus الحالية لا تحتوي Android SDK، لذلك تعذر تشغيل Gradle محليًا في هذه الجلسة. سيعاد تشغيل الاختبار تلقائيًا عبر GitHub Actions بعد دفع التغييرات.

آخر حالة مرصودة بعد دفع التصحيح: فحص الأسرار ناجح، وBuild وCodeQL قيد التشغيل؛ لا يُعلن نجاح البناء قبل اكتمالهما.

## جولة المتابعة — 13 نوفمبر 2026

نُشرت Edge Function باسم `qabas-key-vault` على مشروع Supabase الأصلي `egkgygbvoeevakwkbvfu`، مع إبقاء التحقق الداخلي من جلسة Supabase Auth لأن الدالة تتحقق من Bearer token بنفسها. كما أضيفت استجابات CORS إلى الدالة المنشورة والنسخة الموجودة في المستودع.

توقفت شاشة المواقيت عن إعادة حساب المواقيت كل ثانية؛ الحساب يحدث فقط عند تغير المدينة أو طريقة الحساب. وأصبح حساب الكاش يشمل `cacheDir` و`externalCacheDir`، بينما يحذف تنظيف الكاش الملفات المؤقتة فقط ويستثني `qabas_video_cache` المستخدم من Media3. كذلك خُفض polling لوحة المطور من 8 ثوانٍ إلى 30 ثانية.

حُدث `SCREEN_DEFECTS.md` لإزالة الملاحظة التاريخية المتناقضة حول `ProjectWorkspace` وتسجيل الحالة الحالية.

لم تُضبط قيمة `QABAS_KEY_VAULT_SECRET` لأن أداة Supabase المتاحة للنشر لا تعرض عملية كتابة أسرار المشروع، ولا يوجد Supabase CLI أو access token في بيئة التنفيذ. يجب ضبط السر من إعدادات Edge Functions في مشروع Supabase نفسه؛ لا ينبغي وضعه في Git أو APK.

لم تُغلق اختبارات الجهاز، screenshots، الدفع الحقيقي، والحذف دون اتصال لأنها تتطلب جهازًا فعليًا أو مزود دفع/قرارًا تشغيليًا خارج الكود.
