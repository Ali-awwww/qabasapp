# Qabas App (قبس) - Firestore Database Schema

This document outlines the NoSQL schema structure used in the Qabas app for tracking the Weekly League, user statuses, and projects.

## 1. Collection: `users`
Stores all registered users and their current subscription/reward statuses.
- **Document ID**: `{userId}` (Firebase Auth UID)
- **Fields**:
  - `has_reward` (Boolean): Indicates if the user currently holds a weekly league reward.
  - `reward_expiry` (Timestamp): The exact date and time the current reward expires.
  - `last_won_at` (Timestamp): The exact date and time the user last won the league.
  - `total_wins` (Number): The total number of times the user has won the weekly league.
  - `is_relative` (Boolean): True if the user is granted full free access (either by reward or relative status).

## 2. Collection: `leaderboard`
Stores the current active rankings and points for the ongoing weekly league.
- **Document ID**: `{userId}`
- **Fields**:
  - `name` (String): Display name of the creator.
  - `points` (Number): Current active points for the week (Resets to 0 for winners or active participants).
  - `rank` (Number): Current position/rank (Calculated dynamically or periodically).
  - `views` (String): Display string for views count.
  - `badge` (String): The title/badge of the creator.
  - `is_eligible` (Boolean): Determines if the user is allowed to participate in the *current* active league. (Set to `false` when they win, reset to `true` when their reward expires).
  - `last_won_at` (Timestamp): Kept in sync with the user profile for easy querying.

## 3. Collection: `system`
Stores global system configurations and state variables.
- **Document ID**: `league_info`
- **Fields**:
  - `end_date` (Timestamp): The exact date and time the current weekly league will end and winners will be processed.

## 4. Collection: `users/{userId}/projects`
Stores the user's saved video projects.
- **Document ID**: `{projectId}` (Auto-generated UUID)
- **Fields**:
  - `title` (String): Project title.
  - `ai_script` (String): Script generated by Gemini.
  - `has_voiceover` (Boolean): Indicates audio status.
  - `updated_at` (Number/Timestamp): Last modification time.
