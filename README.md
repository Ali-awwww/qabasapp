# استوديو قبس (Qabas Studio)

تطبيق أندرويد متكامل لصناعة المحتوى المرئي، القرآني، والذكاء الاصطناعي بلغة Kotlin و Jetpack Compose ومربوط بقاعدة بيانات Supabase.

## التوقيع والـ CI/CD (GitHub Actions)
يحتوي المستودع على مفتاح التوقيع الثابت (`debug.keystore.base64`) لضمان توافق تحديثات التطبيق وتجنب أخطاء بناء APK في GitHub Actions.
