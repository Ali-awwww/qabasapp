# قبس — المساعد الإسلامي (Muslim Assistant)

> تطبيق أندرويد متكامل للمستخدم المسلم، يجمع العبادات اليومية والمحتوى الإسلامي ومساعد الذكاء الاصطناعي، ضمن مشروع «استوديو قبس» (Qabas Studio) لصناعة المحتوى المرئي والقرآني.

## ما هو التطبيق؟

«قبس» هو المساعد الإسلامي للمستخدم اليومي: تطبيق أندرويد مبني بلغة Kotlin وواجهات Jetpack Compose، يهدف إلى أن يكون رفيقاً واحداً للصلاة والقرآن والأذكار ومعرفة مواقيت العبادة، مع محتوى إسلامي منظم ومساعد ذكاء اصطناعي يجيب عن الأسئلة ويصنع المحتوى.

## ماذا يفعل؟ وأهم الميزات

- **مواقيت الصلاة والأذان:** عرض مواقيت الصلاة والتذكير بها، مع إشعارات وتذكير في الخلفية.
- **القرآن الكريم والأذكار:** محتوى قرآني وأذكار الصباح والمساء وأذكار متنوعة.
- **اتجاه القبلة والتاريخ الهجري:** تحديد اتجاه القبلة وعرض التاريخ الهجري.
- **العبادات:** مواضيع الصيام والزكاة والحج، وتحديد المساجد القريبة، ومحاضرات العلماء.
- **مساعد ذكاء اصطناعي:** محادثة مع مساعد ذكاء اصطناعي، ومحادثة المطوّر بأسلوب واتساب.
- **استوديو قبس:** صناعة المحتوى المرئي والقرآني من داخل المشروع.
- **حفظ البيانات محلياً:** حفظ البيانات في قاعدة بيانات محلية على الجهاز، والعمل دون اتصال حيث أمكن.

## التقنيات المستخدمة

- **اللغة والواجهة:** Kotlin وJetpack Compose وMaterial 3
- **البنية:** MVVM مع Hilt لحقن التبعيات
- **التخزين والمهام:** Room للتخزين المحلي، وWorkManager للمهام والتذكير في الخلفية
- **الخلفية:** Supabase وFirebase
- **بيئة البناء:** Android Studio، وJDK 17، وGradle 8.14، وAndroid Gradle Plugin 8.13.0، وSDK 36، والحد الأدنى للنسخة المدعومة minSdk 26

## التثبيت والاستخدام

### للمستخدم

1. حمّل أحدث نسخة من قسم [Releases](https://github.com/Ali-awwww/muslim-assistant/releases) في هذا المستودع، أو من نتائج البناء في GitHub Actions.
2. ثبّت ملف APK على جهاز أندرويد، وافتح التطبيق وامنحه أذونات الموقع والإشعارات للاستفادة من مواقيت الصلاة والقبلة والمساجد القريبة.

### للمطوّر (التشغيل من المصدر)

```bash
git clone https://github.com/Ali-awwww/muslim-assistant.git
cd muslim-assistant
```

1. افتح المشروع في Android Studio.
2. انسخ ملف `.env.example` إلى `.env`، وملف `local.properties.example` إلى `local.properties`، واملأ المفاتيح والإعدادات المطلوبة.
3. ابنِ التطبيق وشغّله من Android Studio، أو من سطر الأوامر:

```bash
./gradlew assembleDebug
```

## بنية المشروع

- `app/` — كود تطبيق أندرويد (المصدر والواجهات والبيانات).
- `docs/` — وثائق المشروع وميزاته.
- `supabase/` — إعدادات ومخطط قاعدة بيانات Supabase.
- `AGENTS.md` و`GEMINI.md` — تعليمات المشروع لوكلاء الذكاء الاصطناعي.
- `CONTRIBUTING.md` — دليل المساهمة.

## للمساهمين والمطوّرين

قبل إجراء أي تعديل على هذا المستودع، اقرأ ملف [AGENTS.md](AGENTS.md) واتبع التعليمات المشتركة الواردة فيه. وإذا كنت تستخدم Gemini أو أحد أدوات Google التي تعتمد ملف تعليمات المشروع، فاقرأ أيضاً [GEMINI.md](GEMINI.md). يحتوي المستودع على مفتاح التوقيع الثابت (`debug.keystore.base64`) لضمان توافق تحديثات التطبيق وتجنب أخطاء بناء APK في GitHub Actions.
