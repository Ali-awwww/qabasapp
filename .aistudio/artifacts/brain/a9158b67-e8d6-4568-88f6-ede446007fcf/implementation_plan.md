# خطة عمل توحيد وتطوير قسم الاستيديو (Unified Studio Hub & BYOK)

تهدف هذه الخطة إلى إعادة هيكلة وتوحيد الأقسام العشوائية والمتعددة داخل قسم الاستيديو في تطبيق "قبس" لتصبح في **3 فئات رئيسية منظمة**، مع إقرار نظام مفاتيح الـ API الخاصة بالمستخدم (BYOK - Bring Your Own Key) للمنصات الخارجية مثل Leonardo.ai و Higgsfield AI.

---

## 1. الفئات الثلاث الأساسية للاستيديو
1. **قسم الفيديوهات (Videos Studio)**:
   - مخصص لتوليد وتحريك الفيديوهات.
   - مدعوم بربط مباشر مع **Higgsfield AI** (باستخدام مفتاح الـ API الخاص بالمستخدم).
   - إمكانية استيراد الصور المولدة مسبقاً لتحريكها.

2. **قسم الصور (Images Studio)**:
   - مخصص لتوليد الصور الاحترافية، الخلفيات، والتصاميم.
   - مدعوم بربط مباشر مع **Leonardo.ai** (بالمفتاح الشخصي للمستخدم).
   - زر إجراء سريع: "إرسال إلى محرر الفيديوهات (Higgsfield)" لتحويل الصورة إلى فيديو متحرك.

3. **قسم الصوت (Audio Studio)**:
   - مخصص لتوليد التعليق الصوتي (Text-to-Speech)، المؤثرات الصوتية، وإدارة الصوتيات.
   - يدمج إمكانيات **VoiceStudio** الحالية.

---

## 2. إدارة مفاتيح الـ API (BYOK - Bring Your Own Key)
- **واجهة إدارة المفاتيح (API Key Manager)**:
  - زر إعدادات مخصص في شاشة الاستيديو يتيح للمستخدم إدخال مفاتيحه الخاصة لكل من Leonardo.ai و Higgsfield AI.
  - التحقق الفوري من صلاحية المفتاح (API Key Validation).
- **التخزين الآمن**:
  - حفظ المفاتيح بشكل مشفر ومحلي تماماً باستخدام `EncryptedSharedPreferences` لضمان الخصوصية والأمان التام.

---

## 3. التكامل وسير العمل (Workflows)
- **الربط بين المنصتين**:
  - عندما يقوم المستخدم بتوليد صورة في قسم **Leonardo.ai**، تظهر له أيقونة "تحريك بواسطة Higgsfield" تنقله مباشرة مع الصورة إلى قسم الفيديوهات لتطبيق تأثيرات الحركة فوراً.
- **إدارة الحالة والواجهة (M3 Design)**:
  - تبويبات سفلية أو علوية سلسة (`Videos`, `Images`, `Audio`).
  - دعم الوضع المظلم والفاتح حسب إعدادات الجهاز بتصميم عصري (Material Design 3).

---

## 4. خطوات التنفيذ التقني
1. **إنشاء نموذج وحفظ المفاتيح (`ApiKeyManager`)**: بناء نظام تخزين مشفر للمفاتيح.
2. **تصميم الشاشة الرئيسية الموحدة (`UnifiedMasterStudioScreen.kt`)**: دمج التبويبات الثلاثة في شاشة واحدة منظمة.
3. **تحديث خدمات الشبكة (`Retrofit / Services`)**: ربط واجهات Leonardo.ai و Higgsfield AI بالمفاتيح المدخلة من المستخدم.
4. **ربط تدفق العمل (Pending Media Bridge)**: تفعيل نقل الصور المولدة إلى قسم الفيديوهات.
