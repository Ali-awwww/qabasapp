# منظومة الفيديوهات الصامتة و«وضع الأثر» (Silent Reels & Al-Athar Mode)

خطة متكاملة لإضافة فرع الفيديوهات الصامتة في لوحة نشر المطور ورفعها للسحابة، وتنزيلها صامتاً في الذاكرة المعزولة لأجهزة المستخدمين مع إشعار HUD عائم للمطور، مع التبديل التلقائي الذكي إلى «وضع الأثر» فور انقطاع الاتصال.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> تم استطلاع تفضيلاتكم الفنية وتأكيد الخيارات التالية:
> - **اسم الوضع المعتمد:** «وضع الأثر» (Al-Athar Mode) — يرمز لبقاء النور والأثر الإيماني حياً في قلب المستخدم حتى عند غياب شبكة الإنترنت.
> - **طريقة مراقبة المطور للمزامنة:** إشعار HUD طافٍ أنيق (Floating Dev HUD) يظهر للمطور حصراً، ويعرض مسارات التخزين المحلية `context.filesDir` ونسبة التقدم وحجم الميديا التراكمي.
> - **سياسة التخزين:** التخزين محلي بحت داخل مجلد التطبيق الخاص والمحمي في الأندرويد (`context.filesDir/silent_reels/`)، بحيث تُحذف المقاطع بالكامل وتلقائياً بمجرد إلغاء تثبيت التطبيق أو مسح بياناته، بلا سقف صارم للعدد لحرية المطور في حقن أي محتوى مبارك.

---

### 1. Overview & Core Concept

* **ما تقدمه المنظومة:**
  1. خيار إضافي حصري للمطور في شاشة `ReelPublishScreen` لنشر مقطع كـ **«فيديو صامت (وضع الأثر)»**.
  2. رفع الفيديو وبياناته تلقائياً إلى السحابة (`Supabase Storage` مع وسم `silent_seed` وتفضيل التخزين التلقائي).
  3. محرك مزامنة صامت في الخلفية (`SilentReelPrefetcher`) يتحقق دورياً عند توفر الإنترنت من وجود فيديوهات صامتة جديدة لم يتم تنزيلها بعد.
  4. تخزين المقاطع وبياناتها التعريفية في مسار التطبيق المحمي (`filesDir/silent_reels/`).
  5. للمطور: ظهور شريط مراقبة HUD طافٍ وتفاعلي يوضح حالة التنزيل ومسار الملف الفعلي وسرعة النقل.
  6. للمستخدم العادي: تتم العملية بخفاء تام دون أي إزعاج أو تنبيهات.
  7. لحظة انقطاع الاتصال (أثناء التصفح أو عند فتح الريلز): يتحول النظام فوراً إلى **«وضع الأثر»** ويعرض الفيديوهات المخزنة محلياً بصفر تأخير (Zero Latency) مع شارة HUD مميزة.

### 2. User Experience & Visual Design

#### أ. شاشة نشر المطور (`ReelPublishScreen`):
* إضافة خيار تبديل أنيق بلون الذهب الإيماني (`GoldPrimary`) أسفل خيارات الفئات مخصص للمطور:
  * زر تبديل أو بطاقة مدمجة: **«فيديو صامت (لوضع الأثر) ✦ نشر مسبق للأوفلاين»**.
  * توضيح مصغر للمطور: *«سيتم سحب هذا المقطع صامتاً إلى أجهزة جميع المستخدمين لتشغيله عند غياب الإنترنت»*.

#### ب. إشعار HUD الطافي للمطور (`SilentSyncDevFloatingHud`):
* بطاقة عائمة نصف شفافة ذات حواف منحوتة (`RoundedCornerShape(12.dp)`) في زاوية الشاشة عند حساب المطور (`aliwalead.2007@gmail.com`):
  * **أيقونة نبض المزامنة:** أيقونة سحابية تنبض بلون الذهب عند بدء التحميل.
  * **مسار التخزين الحقيقي:** `.../files/silent_reels/athar_xyz.mp4` بخط تقني أنيق (`RobotoMonoFont`).
  * **مؤشر التقدم:** شريط تقدم دقيق (Progress Bar) مع نسبة مئوية وحجم الميغابايت (`2.4MB / 12.8MB`).
  * **إمكانية الطي والتوسيع:** نقرة واحدة لتقليص الـ HUD إلى كبسولة صغيرة أو توسيعه لتفاصيل الفحص.

#### ج. واجهة الريلز في «وضع الأثر» (`ReelsScreen`):
* شارة علوية طافية بلون التركواز الداكن والذهبي عند غياب الشبكة:
  * **«وضع الأثر ✦ نفحات من وحي السكينة دون اتصال»**
* تصفح عمودي فوري بين المقاطع المحفوظة محلياً دون انتظار للتخزين المؤقت (Buffering = 0s).
* حفظ الإعجابات وتفاعلات المستخدم في قائمة انتظار محلية للمزامنة لاحقاً عند عودة الإنترنت.

### 3. Key Product Decisions & Trade-Offs

* **موقع التخزين (Internal App Sandbox):**
  * *الخيار المعتمد:* الاعتماد على `context.filesDir/silent_reels/` بدلاً من بطاقة الذاكرة الخارجية أو الكاش العادي المعرض للمسح التلقائي لنظام التشغيل عند انخفاض الذاكرة.
  * *السبب:* هذا المسار محمي بصلاحيات نظام أندرويد (لا يمكن لأي تطبيق آخر العبث به)، ويضمن الحذف التلقائي النظيف بمجرد مسح بيانات التطبيق أو إزالته كما طلب المستخدم تماماً.

* **آلية تمييز الفيديوهات في السحابة:**
  * *الخيار المعتمد:* حفظ وسم `silent_seed` ضمن حقل `tags` في `ReelRow` في جدول `reels` بـ Supabase مع تخزين الرابط في Supabase Storage.
  * *السبب:* تجنب تعديل هيكل قاعدة البيانات الحالية أو التسبب بأي كسر في الـ Migration، مع الحفاظ على أعلى سرعة استعلام.

* **مراقبة الشبكة اللحظية:**
  * *الخيار المعتمد:* استخدام `ConnectivityManager.NetworkCallback` لاكتشاف انقطاع الاتصال خلال أجزاء من الثانية أثناء تمرير الريلز والتبديل دون إعادة رسم الشاشة من الصفر.

### 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────┐
│           ReelPublishScreen (Developer Mode)           │
│  [x] تفعيل: فيديو صامت لوضع الأثر (tags: silent_seed)    │
└───────────────────────────┬────────────────────────────┘
                            │ (Upload to Cloud)
                            ▼
┌────────────────────────────────────────────────────────┐
│             Supabase Cloud (Storage & DB)              │
│       reels_bucket / row: tags=["silent_seed", ...]    │
└───────────────────────────┬────────────────────────────┘
                            │
               (Periodic / Network Detection)
                            ▼
┌────────────────────────────────────────────────────────┐
│              SilentReelPrefetcher Service              │
│   - يفحص المقاطع الموسومة صامتة                         │
│   - يقارن بالملفات الموجودة في context.filesDir        │
│   - ينزل الفيديوهات غير الموجودة محلياً                │
└─────────────┬────────────────────────────┬─────────────┘
              │ (For Developer Only)       │ (All Users)
              ▼                            ▼
┌───────────────────────────┐ ┌───────────────────────────┐
│  SilentSyncDevFloatingHud │ │   context.filesDir/       │
│  - مسار الملف ونسبة التقدم│ │     silent_reels/         │
└───────────────────────────┘ └────────────┬──────────────┘
                                           │
                           (Network Disconnect Detected)
                                           ▼
                              ┌───────────────────────────┐
                              │  ReelsScreen: وضع الأثر   │
                              │  - تشغيل فوري file:///... │
                              │  - شارة HUD علوية أنيقة   │
                              └───────────────────────────┘
```

#### المكونات البرمجية التي سيتم إنشاؤها وتحديثها:
1. **`SilentReelStorageManager.kt`:**
   * إدارة المجلد المحلي `context.filesDir/silent_reels/`.
   * تخزين الميتاداتا وملفات الفيديو وحذفها وإحصاء المساحة.
2. **`SilentReelPrefetcher.kt`:**
   * المحرك المسؤول عن الفحص الدوري الصامت وجلب الروابط وتنزيلها مع حساب تقدم التحميل وبث الحالة عبر `StateFlow`.
3. **`SilentSyncDevFloatingHud.kt`:**
   * الـ HUD العائم المتطور للمطور لمشاهدة مسار التخزين ونسبة التحميل وسجل المزامنة.
4. **تحديث `ReelPublishScreen.kt`:**
   * إضافة خيار "فيديو صامت (وضع الأثر)" للمطور وربطه بعملية النشر والوسم.
5. **تحديث `ReelsScreen.kt`:**
   * إضافة كاشف التبديل اللحظي لـ «وضع الأثر» عند انقطاع الإنترنت وتشغيل الفيديوهات المخزنة محلياً بمرونة تامة.
