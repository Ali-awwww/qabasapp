# On-Device Offline Models & Download Center Plan

خطة معمارية وتصميمية متكاملة لإضافة **الوجه الآخر لقسم الوكيل الذكي**: تشغيل النماذج البرمجية الذكية محلياً على جهاز المستخدم دون الحاجة لاتصال بالإنترنت أو مفاتيح API، عبر **مركز تنزيل تفاعلي** بمؤشرات تقدم حقيقية ومفتاح تحويل مباشر في رادار الوكيل.

---

## 1. قرارات التوضيح ومطالب المستخدم (User Review Alignment)

بناءً على التوضيحات المعتمدة مع المستخدم:
- **نطاق ونوع النماذج**: نماذج متوازنة ومضغوطة بصيغة GGUF (تجمع بين القوة البرمجية المناسبة والحجم المعقول غير المستنزف للهاتف والذاكرة).
- **مركز التنزيل والإدارة**: نافذة تفاعلية مدمجة تعرض قائمة النماذج الجاهزة، حجم كل ملف، المتطلبات، شريط تقدم التنزيل الفعلي، خيار الحذف لتحرير المساحة، وتنبيه عند الجاهزية.
- **التفعيل داخل رادار الوكيل**: إضافة **مفتاح تحويل مباشر (Direct Switcher Pill)** في رادار الفحص والمحرك بين:
  1. `الوضع السحابي (Cloud API)`: عبر Gemini أو Groq أو OpenRouter بالمفاتيح الحية.
  2. `الوضع المحلي المباشر (On-Device Offline)`: عبر النموذج المنزّل على الهاتف بدون أي اتصال خارجي.

## 3. المعمارية التقنية والتنفيذ (Technical Architecture)

### أ. محرك إدارة وتنزيل النماذج (`OnDeviceModelManager.kt`)
- هيكل بيانات النموذج:
  ```kotlin
  data class OnDeviceModelInfo(
      val id: String,
      val name: String,
      val tag: String,
      val sizeBytes: Long,
      val sizeFormatted: String,
      val downloadUrl: String,
      val fileName: String,
      val ramRequirement: String,
      val description: String,
      val isRecommended: Boolean
  )
  ```
- وظائف التنزيل والتحقق الحقيقية:
  - التنزيل التدريجي بواسطة OkHttpClient أو Ktor مع Stream Buffer.
  - حساب نسبة التقدم وحجم البايتات المحملة بالثانية لحظياً.
  - تخزين الملفات في `context.filesDir/models/local/` بأمان.
  - فحص وجود الملف وحجمه للتحقق من سلامة الاكتمال.
  - إمكانية حذف النموذج بضغطة زر لاستعادة مساحة الهاتف.

### ب. محرك الاستدلال المحلي (`LocalAgentInferenceEngine.kt`)
- التحقق من حالة النموذج المختار في الهاتف.
- استخدام محرك التنفيذ المحلي المتوافق دون وهم، وتوليد الاستجابات والحلول البرمجية محلياً.
- معالجة حالات عدم توفر النموذج أو نقص الذاكرة برسائل توجيهية صريحة.

### ج. واجهة مركز التنزيل التفاعلي (`OnDeviceModelDownloadDialog.kt`)
- تصميم Cybernetic Glassmorphic أنيق.
- بطاقات لكل نموذج تتضمن:
  - اسم النموذج وشارة التميز وحجم الملف.
  - مؤشر الحالة: "غير مثبت" / "جاري التنزيل مع النسبة المئوية والحجم المنزّل" / "جاهز ومثبت بالكامل ✅".
  - زر تنزيل مباشر بزر إيقاف أو حذف عند التثبيت.
  - زر "تعيين كنموذج افتراضي للوكيل".

### د. تحديث رادار وشاشة الوكيل (`AiStudioAgentScreen.kt`)
- إضافة محول الوضع (Execution Mode Switcher):
  - `سحابي (Cloud API)` مقابل `محلي (On-Device Offline)`.
- عند اختيار الوضع المحلي:
  - يعرض رادار الوكيل فوراً حالة النموذج المحلي (مثبت / غير مثبت / الحجم / الرام).
  - عند الضغط على الرادار أو بطاقة المحرك، تفتح نافذة مركز التنزيل التفاعلي مباشرة.
  - تنفيذ مهام الوكيل يتم توجيهه محلياً بنسبة 100% دون طلب مفتاح API.

- خلو التنفيذ من التأخيرات المصطنعة أو الردود الوهمية.

- فحص البناء النهائي عبر `compile_applet`.
