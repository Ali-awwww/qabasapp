# خطة تطوير ودمج قسم "استوديو الوكيل الذكي" (AI Studio Agent) في التنقل السفلي

تهدف هذه الخطة إلى ترقية **استوديو الوكيل الذكي (`AiStudioAgentScreen`)** ليصبح قسماً رئيسياً متكاملاً يظهر مباشرة في شريط التنقل السفلي (Bottom Navigation Bar) في تطبيق "قبس"، مع الاحتفاظ بهدفه الأساسي كوكيل برمجي (Code Agent) لتوليد الأكواد، تحليل الأخطاء، تخطيط المهام، وتنفيذ مهام التطوير بسلاسة.

---

## 1. ترقية شاشة `AiStudioAgentScreen.kt`
- **إضافة وضع شريط التنقل السفلي**: دعم عرض الشاشة كعلامة تبويب رئيسية (Tab) في التنقل السفلي بدلاً من مجرد شاشة فرعية عادية، مع إخفاء سهم الرجوع أو توجيهه للرئيسية عند الحاجة.
- **إثراء قدرات الوكيل البرمجي (Code Agent Capabilities)**:
  - إضافة تبويبات ذكية داخل الاستوديو:
    1. **محادثة وتوجيه الوكيل (Agent Chat & Mission Control)**: إعطاء مهام باللغة الطبيعية مع خطوات تفكير مرئية (Planning -> Inspecting -> Writing -> Building).
    2. **سجل المهام والملفات المعدلة (Modified Files & Sessions)**: استعراض الملفات التي قام الوكيل بتعديلها أو توليدها.
    3. **التشخيص والبناء التلقائي (Build & Diagnostics Hub)**: فحص أخطاء البناء والربط السحابي مع Firebase مباشرة من لوحة الوكيل.

---

## 2. تحديث شريط التنقل السفلي وربط القسم الجديد (`QabasHomeScreen.kt` أو مدير التنقل الرئيسي)
- **إضافة أيقونة وزر الوكيل للسفلي**:
  - إضافة عنصر تنقل جديد في الشريط السفلي باسم **"الوكيل الذكي 🤖"** (أو **"Agent Studio"**) بأيقونة مميزة (`Icons.Default.SmartToy` أو `AutoAwesome`) وتصميم فضائي HUD متناسق مع ثيم قبس الملكي.
- **التوجيه السلس**:
  - الضغط على أيقونة الوكيل في الشريط السفلي يفتح فورا `AiStudioAgentScreen` مع استمرار عمل الخدمات الخلفية والمزامنة السحابية.

---

## 3. التحقق والتحقيق
- اختبار تجميع المشروع والتأكد من توافق الروافد عبر `compile_applet`.
- ضمان عمل ميزات الكود إيجنت بكفاءة تامة.
