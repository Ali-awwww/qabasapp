# التنزيل التلقائي لتحديثات التطبيق وإدراجها في مركز التنزيلات

تنفيذ دورة فحص وتنزيل تلقائية لتحديثات التطبيق الرسمية عبر GitHub Releases، وربط تقدم التنزيل في الوقت الفعلي مع مركز التنزيلات الموحّد (Downloads Hub)، مع إطلاق نافذة تثبيت النظام تلقائياً فور اكتمال التنزيل.

### قرارات المستخدم المؤكدة

> [!IMPORTANT]
> تم تأكيد الخيارات التالية بناءً على إجابات المستخدم:
> - **مصدر التحديث**: فحص الإصدارات الجديدة الرسمية عبر **GitHub Releases**.
> - **سلوك التنزيل**: بدء التنزيل **تلقائياً وفوراً** عند اكتشاف إصدار أحدث، مع بث تقدم التنزيل في **مركز التنزيلات**.
> - **سلوك ما بعد التنزيل**: فتح **نافذة تثبيت النظام تلقائياً** فور اكتمال التنزيل، مع إتاحة زر التثبيت اليدوي في مركز التنزيلات.

---

### 1. نظرة عامة والهدف الأساسي

- **ما تقدمه الميزة**: عند تشغيل التطبيق أو انتقال المستخدم للواجهة، يقوم النظام بفحص أحدث إصدار في GitHub Releases ومقارنته بالإصدار الحالي (`versionCode` و `versionName`). إذا وجد إصداراً أحدث، يبدأ فوراً بتنزيل حزمة التحديث (APK أو Delta) في الخلفية، ويظهر التحديث كبطاقة حية في شاشة مركز التنزيلات (`DownloadsHubScreen`) تعرض نسبة التقدم وسرعة التنزيل والحجم وملاحظات الإصدار، وبمجرد اكتمال التنزيل يُطلب من نظام أندرويد فتح حزمة التثبيت فوراً.
- **القيمة المضافة**: الحفاظ على تحديث التطبيق دائماً لأحدث نسخة للمستخدم دون الحاجة للبحث اليدوي أو مغادرة التطبيق إلى المتصفح، مع شفافية كاملة لحالة التنزيل واستهلاك الذاكرة داخل مركز التنزيلات.

---

### 2. تجربة المستخدم والتصميم البصري (Spatial HUD)

- **تدفق تجربة المستخدم**:
  1. يبدأ التطبيق في فحص التحديثات في الخلفية بدون تجميد الواجهة.
  2. في حال وجود تحديث جديد:
     - يظهر مؤشر نبضي/إشعار لطيف في الـ Top Bar ومركز التنزيلات.
     - يتم تسجيل عنصر تنزيل نشط للتحديث في `DownloadsHubManager`.
     - يستطيع المستخدم الذهاب إلى مركز التنزيلات لرؤية شريط تقدم التنزيل، السرعة الحالية (MB/s)، الحجم الإجمالي، وملاحظات الإصدار (Release Notes).
  3. فور انتهاء التنزيل:
     - يتم استدعاء مُثبّت الحزم النظامي (`PackageInstaller` عبر `FileProvider`).
     - تظهر في مركز التنزيلات بطاقة خضراء تُمكّن المستخدم من إعادة تشغيل التثبيت بنقرة واحدة إذا ألغى النافذة.

- **التصميم البصري**:
  - يتناغم تماماً مع أسلوب **Cybernetic Glassmorphism + Linear Minimalist**:
    - بطاقات زجاجية عاكسة (`CardSurface` مع حواف ذهبية نيون `BorderGold`).
    - شريط تقدم ديناميكي متدرج بالألوان (`AccentCyan` إلى `GoldPrimary`).
    - شارات حالة واضحة: `[تحديث قيد التنزيل]`، `[جاهز للتثبيت]`.

### 4. خطة التعديلات التنفيذية

1. **توسيع `DownloadsHubManager`**:
   - إضافة حالة لمتابعة تحديث التطبيق: `appUpdateDownloadState: StateFlow<AppUpdateDownloadStatus>`.
   - تخزين تفاصيل الإصدار الجديد (رقم الإصدار، الحجم، الرابط، التقدم، المسار المحلي للـ APK).
   - توفير دوال: `startAutoUpdateDownload()`, `installDownloadedUpdate()`, `cancelUpdateDownload()`.

2. **ربط `UpdateManager` مع `DownloadsHubManager`**:
   - عند اكتشاف تحديث بواسطة `UpdateManager.checkForUpdate()` أو فحص البداية التلقائي:
     - استدعاء التنزيل التلقائي عبر `DownloadsHubManager` وتحديث نسب التقدم في الوقت الفعلي.
     - فور اكتمال تنزيل الملف، التحقق من سلامة الملف واستدعاء `UpdateManager.launchInstaller(context, apkFile)`.

3. **تحديث واجهة `DownloadsHubScreen`**:
   - إضافة شريحة أو بطاقة بارزة خاصة بـ **تحديث النظام** أعلى الشاشة أو داخل تبويب مخصص.
   - عرض حالة التحميل الحالية، السرعة، الوقت المتبقي المقدر، وإمكانية إيقاف/استئناف أو إعادة تثبيت الحزمة.

4. **تشغيل الفحص التلقائي في `MainActivity`**:
   - بدء الفحص الصامت عند إطلاق التطبيق، وفي حال ثبوت وجود تحديث، تفعيل التنزيل وإرسال إشعار للمستخدم بأن التحديث بدأ تنزيله وظاهر في مركز التنزيلات.
