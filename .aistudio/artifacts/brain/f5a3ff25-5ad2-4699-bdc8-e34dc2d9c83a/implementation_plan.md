# خطة التحقق المسبق من توفر الحساب قبل إنشائه مع الإشعارات التفاعلية

تهدف هذه الخطة إلى إضافة نظام تحقق استباقي ذكي في شاشة إنشاء الحساب (`RegisterScreen`)، بحيث يتحقق التطبيق من أن **البريد الإلكتروني** و**اسم المستخدم المخصص** غير مستخدمين مسبقاً، مع إظهار مؤشرات حية أثناء الكتابة، وعرض **تنبيه تفاعلي فوري** يتيح للمستخدم الانتقال المباشر لتسجيل الدخول أو استعادة حسابه إذا تبين أن الحساب موجود بالفعل.

---

## القرارات المؤكدة بناءً على إجاباتك

- **البيانات المفحوصة**: فحص **البريد الإلكتروني** و**اسم المستخدم المخصص (custom_id)** معاً.
- **توقيت الفحص**: فحص حي لحظي أثناء الكتابة (Debounced Live Check) + فحص جازم حاسم عند الضغط على زر "إنشاء الحساب".
- **شكل الإشعار التفاعلي**: بطاقات حالة حية أسفل الحقول + نافذة حوارية تفاعلية منبثقة (Interactive Alert Dialog) عند اكتشاف حساب مسجل مسبقاً، تتيح:
  1. زر **"تسجيل الدخول فوراً"** (ينقل البريد تلقائياً لشاشة الدخول).
  2. زر **"استعادة كلمة المرور"** (إرسال رابط إعادة التعيين).
  3. زر **"تعديل البيانات"**.

---

## 1. المعمارية وتدفق البيانات (Architecture & User Flow)

```
┌────────────────────────────────────────────────────────┐
│             شاشة إنشاء الحساب (RegisterScreen)         │
│  - حقل البريد الإلكتروني                               │
│  - حقل اسم المستخدم (custom_id)                       │
└───────────────────────────┬────────────────────────────┘
                            │ (أثناء الكتابة 400ms Debounce)
                            ▼
┌────────────────────────────────────────────────────────┐
│           Supabase Account Availability Engine         │
│  - RPC سحابي: check_account_availability(email, user)  │
│  - فحص مباشر لجدول public.users                        │
└───────────────────────────┬────────────────────────────┘
                            │
               ┌────────────┴────────────┐
               ▼                         ▼
         [الحساب متاح ✅]         [الحساب مسجل مسبقاً ⚠️]
     - شارة خضراء تفاعلية        - شارة حمراء تنبيهية
     - تفعيل زر الإنشاء           - نافذة تفاعلية ذكية:
                                  • تسجيل الدخول فوراً
                                  • استعادة كلمة المرور
```

## 2. التحسينات البرمجية التفصيلية

### أ) إضافة فحص السحابة في `SupabaseServices.kt`
- إضافة دالة `checkAccountAvailability(email: String?, customId: String?)`:
  - تستعلم من سحابة Supabase لمعرفة ما إذا كان البريد أو المعرف مسجلاً في جدول `users`.
  - تُرجع كائناً يحتوي على:
    ```kotlin
    data class AccountAvailability(
        val isEmailTaken: Boolean = false,
        val isCustomIdTaken: Boolean = false,
        val isChecking: Boolean = false,
        val error: String? = null
    )
    ```

### ب) إضافة هجرة SQL لدالة RPC سريعة وآمنة في `supabase/migrations/`
- دالة `check_account_availability(p_email text, p_custom_id text)` آمنة ومفتوحة للزوار دون كشف أي بيانات شخصية (ترجع فقط `boolean` يوضح هل الحساب محجوز أم متاح).

### ج) تحديث شاشة إنشاء الحساب (`AuthScreens.kt`)
1. **مؤشرات لحظية أسفل الحقول**:
   - حقل البريد:
     - إذا كان متاحاً: `✓ هذا البريد متاح للاستخدام` باللون الأخضر الزمردي.
     - إذا كان محجوزاً: `⚠️ هذا البريد مسجل مسبقاً في قبس` باللون الأحمر التحذيري مع زر صغير "تسجيل الدخول".
   - حقل اسم المستخدم:
     - إذا كان متاحاً: `✓ المعرف متاح`.
     - إذا كان محجوزاً: `⚠️ هذا المعرف مستخدم، يرجى اختيار معرف آخر`.
2. **النافذة التفاعلية عند محاولة الإنشاء (Interactive Conflict Dialog)**:
   - إذا ضغط المستخدم على زر "إنشاء الحساب" وكان البريد مستخدماً:
     - لا يظهر مجرد خطأ نصي جاف، بل تنبثق نافذة تفاعلية فاخرة:
       - **عنوان**: "الحساب مسجل مسبقاً 🔑"
       - **نص**: "البريد الإلكتروني (user@example.com) مسجل بالفعل في مجتمع قبس. هل ترغب في تسجيل الدخول إليه؟"
       - **الأزرار التفاعلية**:
         - زر أساسي: `تسجيل الدخول الآن` (يفتح شاشة الدخول مع تعبئة البريد تلقائياً).
         - زر ثانوي: `استعادة كلمة المرور` (إرسال رمز إعادة التعيين فوراً).
         - زر إلغاء: `تغيير البريد`.

## 3. خطة التحقق والاختبار (Verification Plan)

1. **التحقق من صحة الكود**:
   - تشغيل `compile_applet` للتأكد من خلو المشروع من أخطاء الترجمة والتوافق.
2. **اختبار السيناريوهات**:
   - إدخال بريد مستخدم مسجل بالفعل (مثل بريد المطور المسجل `aliwalead.2007@gmail.com`) والتحقق من ظهور الشارة الحمراء وظهور النافذة التفاعلية مع خيارات تسجيل الدخول.
   - إدخال بريد جديد تماماً والتأكد من إضاءة الشارة الخضراء ونجاح التسجيل.
   - اختبار اسم مستخدم محجوز واسم مستخدم متاح.
